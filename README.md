# car-sales-powerbi-dashboard


## Overview
3-page interactive dashboard analysing vehicle sales.

## Pages
1. Dashboard: KPIs, monthly trend, gender and age share
2. Vehicle Analysis: brand, model, fuel type, transmission
3. Customer Analysis: city, payment mode, repeat customers

## Tools
Power BI, DAX, Power Query
